# Takayuki Kimura

福岡を拠点に、データ移行・ETL・品質設計・自治体業務システムに取り組むソフトウェアエンジニアです。

プログラミング、ユビキタス研究、大規模SI、iOS開発などの経験を生かし、現場で確実に動き、長く運用できる仕組みづくりを大切にしています。

- 大規模データ移行、ETL、CSV検証、データ差分比較
- FastAPI / Spring Boot / OutSystems
- Linux、バッチ処理、運用設計、障害調査
- RAG、生成AIを活用した業務支援
- 若手エンジニアの育成、レビュー、技術の標準化

## 現在取り組んでいること

- データ移行の品質を高める検証ツールの開発
- 公共分野で活用できるRAG・生成AIの研究と試作
- 長年の技術経験を、若手が利用できる教材や開発手順として整理
- AIを活用し、エンジニアの生産性を高める方法の実践

## これから実現したいこと

これまで蓄積してきた技術を、社会や次の世代のために役立てたいと考えています。

特に、学ぶ意欲がありながら環境に恵まれない若者や子どもたちが、IT技術を身につけ、自分の力で将来の選択肢を広げられるような活動につなげていきたいと思っています。

## 公開予定のプロジェクト

- **CSV Validator** — データ移行前に、必須項目、主キー、型、桁数、日付などを検証するツール
- **Database Migration Checker** — MySQL・OracleからPostgreSQLへの移行結果を確認するツール
- **Public-sector RAG Demo** — 架空の行政文書を使い、回答根拠を示すRAGデモ
- **Engineering Playbook** — データ移行、障害調査、レビュー、品質管理の実践的な手引き

## 大切にしていること
私は、単に「プログラムが動けばよい」とは考えていません。

利用する人の仕事や生活を理解し、安心して長く使える仕組みを作ることを大切にしています。そのために、コードだけでなく、なぜその設計にしたのか、どのような問題があり、どう解決したのかを言葉にして残します。

また、成功した方法だけでなく、失敗や試行錯誤から得た知識も、次の人が活用できる形に整理したいと考えています。経験を個人の中だけに蓄えるのではなく、手順、チェックリスト、サンプルコード、教材として共有することで、若手エンジニアや学ぶ機会の少ない人の成長を支えます。

特に公共分野や子どもに関わるシステムでは、効率だけでなく、個人情報を守ること、誤りを見逃さないこと、現場の職員が安心して利用できることを重視します。技術は人のために使われてこそ価値がある、という姿勢を忘れません。
